
# MYBIKE Landing Page

## Короткий опис проєкту
Лендінг-сторінка для велосипедного бренду з сучасним адаптивним дизайном, інтерактивними секціями та контактною формою.

## Технології, які було використано
- HTML5
- SCSS (Sass)
- JavaScript (ES6)
- Cypress (тестування)
- Git/GitHub Pages для деплойменту

## Посилання
- Прев'ю: [https://deny-hl.github.io/layout_landing-page/](https://deny-hl.github.io/layout_landing-page/)
- Макет: [MYBIKE landing](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## Інструкції для запуску
1. Клонувати репозиторій:
	```bash
	git clone https://github.com/deny-hl/layout_landing-page.git
	cd layout_landing-page
	```
2. Встановити залежності:
	```bash
	npm install
	```
3. Запустити локальний сервер:
	```bash
	npm start
	```
4. Для запуску тестів:
	```bash
	npm run test
	```
